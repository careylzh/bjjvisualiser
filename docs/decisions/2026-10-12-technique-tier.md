# D-4 — Fundamentals first: an editorial `tier` on technique entries

**Date:** 2026-10-12 · **Asked by:** the PI, testing on a phone: *"prioritise the simpler techniques
like americana, armbar, kimura over the fancy ones like electric chair, crucifix and banana split."*

## Ruling
Technique entries take an optional `tier`: `"fundamental"` or `"advanced"`. Omitted = in between.
The panel sorts every tab **fundamental → untiered → advanced**, then (attacks) primary-target
first, then by name, and draws a "More advanced" divider before the first advanced entry.

- `tier` is **editorial revision priority, not a factual claim**, so it needs no source. It is not
  shown as a badge and never hides an entry. The build only checks the value is one of the two words.
- **fundamental** = what a typical white-belt curriculum teaches first (Americana, kimura,
  armbars from guard/mount/side/back, triangle, RNC, guillotine, cross-collar, arm triangle,
  omoplata, straight ankle lock, the core grips and pins).
- **advanced** = specialist systems and rarer finishes (crucifix family, electric chair, banana split,
  twister, the -platas beyond the omoplata, neckties, slicers, 50/50 and saddle entries, cranks).
- First pass made by Claude on 2026-10-12 (66 of 104 entries tagged); the knowledge-curator and
  the PI should adjust it. Moving an entry between tiers is a **patch**.
